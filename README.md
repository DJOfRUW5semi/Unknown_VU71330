# Guided module sample (.NET)

The companion walkthrough covers publishing a WebAssembly front end together with a serverless .NET API.

## Static hosting starter

The folders here are starting points for a set of guided lessons.

A shopping theme runs through all of them so the lessons stay comparable.

## What is inside

A WebAssembly client plus a serverless C# API.

## What you should already know

- Some familiarity with WebAssembly front ends
- Beginner-level experience with serverless functions
- An account on the code host
- Node.js and git installed
- An editor or full IDE installed
- The serverless extension for your editor
- The serverless local runtime
